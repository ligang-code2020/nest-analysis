## Pipes 模块
管道是一个用 @Injectable() 装饰器注解的类，它实现了 PipeTransform 接口。

```ts
/* Pipes 生命周期图形
┌──────────────────────┐
│   1. HTTP 请求到达    │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│   2. Middlewares     │ ← 可以修改 req/res、决定是否继续
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│   3. 路由匹配完成      │ ← 找到对应的 Controller 和方法
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│   4. Guards (守卫)    │ ← 鉴权判断：是否有权限访问该路由
└──────────┬───────────┘
     ┌────┴────┐
     ▼         ▼
  允许访问    拒绝访问
     ▼         ▼
┌────────┐  ┌────────────┐
│ 5. Pipes │  Exception Filters
│ 参数转换/验证│← 抛出异常统一处理
└────────┘  └────────────┘
           ▼
┌──────────────────────┐
│ 6. Controller 方法执行 │ ← 真正的业务逻辑开始
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 7. Interceptor 前置阶段│ ← 可对返回值进行包装或处理
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 8. 返回响应给客户端   │ ← 最终输出 JSON / HTML / 文件等
└──────────────────────┘
           ▼
┌──────────────────────┐
│ 9. Interceptor 后置阶段 │ ← 日志记录、缓存更新等操作
└──────────────────────┘

 */
```
